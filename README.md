# Company Analyst BI — настольное приложение для анализа компаний по ИНН

Это **desktop-приложение на PySide6**, а не сайт. Оно предназначено для точечного сбора публичной бухгалтерской отчётности российских организаций по ИНН, сравнения нескольких компаний, построения аналитического отчёта и полноценного интерактивного BI-дашборда на Altair/Vega-Lite.

## Что уже реализовано

- Постоянная верхняя навигация: **Главная / История / Настройки**.
- Поле ИНН с поддержкой нескольких значений: `ИНН1/ИНН2/ИННx` (также допускаются пробелы, запятые и `;`).
- Поле **«Название файла / анализа»** — это имя сохраняемой записи, по которому потом работает поиск в «Истории».
- Выбор конечного отчётного года и глубины периода от 1 до 7 лет в раскрывающемся списке; по умолчанию загружаются 5 лет.
- Кнопка **«Выполнить»** запускает сбор данных в отдельном потоке, поэтому интерфейс не зависает.
- Таблица содержит год, название, ИНН, выручку, себестоимость, прибыль/убыток, убыток, расходы, активы, капитал, кратко- и долгосрочные обязательства, маржу, ROA, ROE, текущую ликвидность, D/E, ОКВЭД, регион, статус и ссылку на источник.
- Кнопка **«Посмотреть отчёт»** открывает отдельное окно с автоматическим сравнительным анализом компаний.
- Кнопка **«Открыть BI-дашборд»** запускает большой отдельный аналитический экран внутри приложения, без открытия браузера.
- Слева находятся фильтры по названию/ИНН, мультивыбор компаний, выбор главного показателя и года сравнительного среза.
- Сверху показаны KPI-карточки: число компаний, совокупная выручка, чистая прибыль/убыток, медианная маржа и совокупные активы.
- Дашборд содержит 9 визуализаций: линейную динамику выручки, чистой прибыли и маржи, а также ранжирование за выбранный год, прибыль/убыток, структуру расходов, баланс и источники финансирования, рентабельность и heatmap коэффициентов.
- Графики связаны: клик по компании на главном графике подсвечивает её во всех остальных визуализациях; двойной клик сбрасывает подсветку.
- Есть отдельная вкладка с таблицей коэффициентов и экспорт всего дашборда в **PNG / SVG / автономный интерактивный HTML**, экспорт выбранного графика в PNG и копирование изображения в буфер обмена.
- Экспорт таблицы в CSV.
- «История» сохраняет полный период в SQLite между запусками, поддерживает поиск по имени/ИНН, открытие, удаление и повторный запрос; старая база обновляется автоматически.
- «Настройки» позволяют менять сетевой таймаут и открывать папку локальной базы.
- Все обращения к ФНС собраны в одном файле `company_analyst/fns_source.py`, чтобы endpoint можно было быстро заменить при изменениях сайта.

## Источник данных

По умолчанию приложение использует публичную веб-витрину ГИР БО ФНС:

- поиск организации: `https://bo.nalog.gov.ru/advanced-search/organizations/search`
- список БФО организации: `https://bo.nalog.gov.ru/nbo/organizations/{organizationId}/bfo/`
- ссылка на PDF-форму: `https://bo.nalog.gov.ru/download/bfo/pdf/{organizationId}?period=YYYY&detailId=...`

Важно: JSON-точки являются backend-вызовами публичной веб-витрины, а не гарантированным бессрочным официальным публичным API. ФНС может менять контракт сайта. Приложение обрабатывает сетевые ошибки и сохраняет их по каждому ИНН отдельно; архитектура источника специально изолирована.

Бухгалтерская отчётность в ГИР БО обычно доступна начиная с 2019 года. У отдельных организаций данные могут отсутствовать или иметь ограничение доступа.

## Быстрый запуск в Windows

### Вариант 1 — два клика

1. Установите **Python 3.11–3.14 (64-bit)** с сайта python.org. Во время установки включите **Add Python to PATH**.
2. Распакуйте архив в папку, где в пути желательно нет очень длинных имён.
3. Запустите `run_windows.bat`. При первом запуске он сам создаст отдельное чистое окружение `.venv_bi`, установит библиотеки и откроет приложение.
4. После завершения запускайте приложение через `run_windows.bat`.

Старое окружение `.venv` намеренно не используется: новая версия работает только с `.venv_bi`, поэтому оставшиеся пакеты предыдущей сборки не могут повлиять на запуск. Отдельный `install_windows.bat` полностью пересоздаёт `.venv_bi`. Совместимые версии графического стека зафиксированы, а для ручного восстановления есть `repair_windows.bat`.

### Вариант 2 — вручную

```powershell
cd company_analyst_desktop
py -3 -m venv .venv_bi
.venv_bi\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

## Как пользоваться

1. На «Главной» введите один ИНН, например `5256038700`, или несколько: `ИНН1/ИНН2/ИНН3`.
2. Введите название анализа, например `Конкуренты — 2025`.
3. Выберите конечный год и глубину периода. Например, `2024` и `5 лет` загрузят 2020–2024 годы.
4. Нажмите **«Выполнить»**.
5. После загрузки:
   - данные появятся в таблице;
   - запись автоматически попадёт в «Историю»;
   - **«Посмотреть отчёт»** откроет подробный сравнительный анализ;
   - **«Открыть BI-дашборд»** откроет отдельный большой аналитический экран;
   - в левой панели можно оставить нужные компании, сменить показатель главного рейтинга и выбрать год сравнительного среза;
   - клик по столбцу компании включает связанную подсветку, двойной клик сбрасывает её;
   - кнопки сверху сохраняют весь дашборд в PNG/SVG, копируют изображение или создают автономный интерактивный HTML;
   - блок слева позволяет сохранить один выбранный график в PNG;
   - двойной клик по колонке **«Источник»** откроет PDF/карточку ФНС в браузере.

## Где хранится история

На Windows база создаётся в:

```text
%APPDATA%\CompanyAnalyst\history.sqlite3
```

Путь можно открыть через **Настройки → Открыть папку данных**.

## Сборка собственного EXE

После обычной установки запустите:

```text
build_windows_exe.bat
```

Скрипт установит PyInstaller и создаст:

```text
dist\CompanyAnalyst\CompanyAnalyst.exe
```

Папку `dist\CompanyAnalyst` можно перенести на другой Windows-компьютер. Для первого промышленного распространения рекомендуется проверить сборку на чистой Windows 10/11 и при необходимости подписать EXE корпоративным сертификатом.

## Аналитические показатели

Приложение автоматически рассчитывает:

- чистую рентабельность = чистая прибыль / выручка;
- ROA = чистая прибыль / активы;
- ROE = чистая прибыль / собственный капитал;
- текущую ликвидность = оборотные активы / краткосрочные обязательства;
- D/E = (долгосрочные + краткосрочные обязательства) / собственный капитал;
- оборачиваемость активов = выручка / активы;
- набор простых риск-сигналов: убыток, ликвидность ниже 1, отрицательный капитал, D/E выше 2.

Автоматический отчёт сравнивает компании за последний доступный год и показывает динамику за период: изменение выручки, среднегодовой темп роста (CAGR), изменение чистой прибыли и маржи. Для кредитного, инвестиционного или юридического решения дополнительно изучайте пояснения, аудиторское заключение, отраслевые нормы и иные источники.

## Тесты

В проект включены 7 офлайн-тестов: выбор глубины периода, парсер ФНС, обработка отсутствующего года, многолетний аналитический отчёт, миграция SQLite, подготовка данных дашборда и реальный экспорт Altair в PNG:

```powershell
pip install pytest

```

Тесты не требуют доступа к сайту ФНС.

## Если ФНС изменила сайт

Если программа внезапно начинает возвращать HTTP 404/400 для всех ИНН, сначала проверьте `https://bo.nalog.gov.ru` в браузере. Затем достаточно обновить пути/структуру ответа в `company_analyst/fns_source.py`; интерфейс, база, история, отчёты и графики от этого не зависят.

## Ошибка `No module named typing_extensions`

В исправленной версии совместимая версия `typing-extensions` зафиксирована явно. Проще всего запустить `repair_windows.bat` или повторно запустить `install_windows.bat`. Для восстановления уже созданного окружения вручную выполните в папке проекта:

```powershell
.venv_bi\Scripts\python.exe -m pip install --upgrade --force-reinstall typing-extensions==4.16.0 altair==5.5.0
```

Эта же команда исправляет ошибку `_TypedDictMeta.__new__() got an unexpected keyword argument 'closed'`.

Altair теперь загружается только при открытии BI-дашборда. Даже если графические библиотеки повреждены, главное окно, сбор данных, история, таблица и текстовый отчёт продолжают запускаться; при открытии дашборда приложение покажет понятную инструкцию по восстановлению.

Для Python 3.14 приложение использует собственный совместимый загрузчик `company_analyst/altair_compat.py`: перед импортом Altair он выбирает реализацию `TypedDict`, поддерживающую параметр `closed`. Поэтому ошибка не зависит от того, какая версия Python выбрана Windows Launcher.

## Технологии дашборда

- **Altair / Vega-Lite** — декларативные интерактивные графики.
- **QWebEngineView** из PySide6 — показ дашборда внутри отдельного окна desktop-приложения.
- **vl-convert-python** — локальный экспорт PNG/SVG без Selenium и внешнего браузера.
- HTML сохраняется с зависимостями внутри файла (`inline=True`), поэтому экспортированный отчёт можно открыть отдельно без установки приложения и без доступа к интернету.
